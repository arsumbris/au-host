SVGs supply unmodified silhouettes to CSS masks. Marks render only in approved black or white, selected with CSS contrast-color from the surface token (the CTA token for Discord). A light-dark fallback follows the active theme colour scheme. There are no backplates or filters. Controls reserve at least one displayed mark-width of clear space using padding and gaps; mask-size:contain preserves proportions. Adjacent text identifies the destination.
